# RepairShop — приложение для ремонтной мастерской электронного оборудования

Курсовой проект по дисциплине «Программная инженерия» (тема № 23).
Язык: C# (.NET 8), интерфейс — Windows Forms.

## Возможности
- приём устройств в ремонт, оформление акта приёма, автоматическая нумерация заказов (`РМ-ГГГГ-NNNN`);
- жизненный цикл заказа: Принят → Диагностика → Ожидание запчастей → В ремонте → Готов к выдаче → Выдан / Отменён
  (недопустимые переходы блокируются);
- работы из прайс-листа и запчасти со склада (автоматическое списание и возврат остатков);
- расчёт стоимости: скидка постоянного клиента (5 % / 10 %), гарантийный ремонт (30 дней) бесплатно,
  оплата диагностики при отказе от ремонта;
- роли «Администратор» и «Мастер», хэширование паролей (SHA-256 + соль);
- поиск и фильтры заказов, подсветка просроченных, отчёты за период, выгрузка в CSV;
- хранение данных в XML-файле (`%APPDATA%\RepairShop\data.xml`).

## Структура
| Папка | Содержимое |
|---|---|
| `src/RepairShop.Core` | модели, бизнес-логика, сервисы, хранилище (без зависимостей от UI) |
| `src/RepairShop.App` | интерфейс Windows Forms |
| `tests/RepairShop.Tests` | 40 модульных тестов (консольный запуск, без внешних пакетов) |
| `docs/screenshots` | скриншоты работающего приложения |

## Запуск
Требуется Windows и .NET 8 SDK (или Visual Studio 2022).
```
dotnet run --project src/RepairShop.App
```
или откройте `RepairShop.sln` в Visual Studio и нажмите F5.

Тесты (работают и на Linux/macOS):
```
dotnet run --project tests/RepairShop.Tests
```

При первом запуске создаётся демонстрационная база. Учётные записи:

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin123` |
| Мастер | `ivanov` | `master123` |
| Мастер | `petrova` | `master123` |
